---

## Project Overview

SketchUp Pro 2026 is a desktop 3D modeling application developed by Trimble. It supports the creation of architectural concepts, interior layouts, furniture, landscape designs, and other three-dimensional models.

The application combines drawing tools, direct geometry editing, measurement controls, reusable components, and material settings. Users can build models from simple shapes, refine dimensions, organize separate elements, and prepare views that communicate the intended design.

LayOut supports the creation of drawing sheets and documentation based on SketchUp models. Import and export tools also help connect model geometry with compatible CAD files and other design resources.

The 2026 edition adds changes to model collaboration, visual settings, memory handling, geometry editing, and DWG interoperability. Its capabilities make it useful for conceptual design, spatial planning, model presentation, and architectural documentation.

## Core 3D Modeling Features

### Drawing and Geometry Editing

SketchUp Pro 2026 includes tools for drawing lines, rectangles, circles, arcs, and other geometric shapes. These elements can be combined and modified to build three-dimensional forms.

The Push/Pull tool turns suitable flat faces into 3D geometry. Move, Rotate, Scale, and Offset controls help adjust dimensions and refine the shape of individual elements.

Inference guides assist with alignment, endpoints, midpoints, and other geometric relationships. These visual references help maintain consistent placement while editing a model.

### Measurements and Dimensions

Measurement tools allow users to work with specified dimensions and consistent proportions. Units can be configured to match the needs of a design, from furniture concepts to building layouts.

The combination of drawing tools and dimensional controls makes it possible to create models with clearly defined measurements rather than relying only on visual estimation.

### Groups and Components

Groups keep separate geometry organized and help prevent unintended changes to neighboring elements. Components support reusable objects that appear repeatedly within a model.

Doors, windows, fixtures, furniture, and structural elements can be represented by component instances. Editing a shared component can update its instances, helping maintain consistency across the model.

### Scenes and Camera Views

Scenes save selected camera positions and display settings. Users can prepare views of different rooms, elevations, building exteriors, or individual details.

Orbit, Pan, and Zoom controls support navigation around the model. Section tools and standard views help inspect geometry from different directions.

## Architecture and Interior Design

### Building Models

SketchUp Pro 2026 supports the creation of building concepts, architectural massing, room layouts, and structural forms. Users can begin with a basic outline and refine individual elements as the design develops.

Three-dimensional models help communicate scale, proportions, and spatial relationships before detailed documentation begins.

### Interior Layouts

Interior designers can model rooms, furniture arrangements, cabinetry, fixtures, and decorative elements. Materials and textures help distinguish surfaces and communicate the intended appearance of an interior.

Working in three dimensions helps evaluate furniture placement, circulation, clearances, and the relationship between architectural elements.

### Furniture and Object Modeling

The geometry tools support the creation of furniture concepts, fixtures, fittings, and other objects. Users can adjust dimensions and shape details while keeping separate elements organized.

Reusable components are useful when an object contains repeated parts or appears in several locations within a design.

### Landscape and Site Design

Site models can represent terrain, buildings, pathways, outdoor spaces, and landscape elements. Suitable location and terrain data can help place a design within its surroundings.

Model accuracy depends on the source data and the requirements of the intended use. Surveying and engineering tasks may require additional specialized tools.

## Materials and Visualization

### Materials and Textures

Material controls allow users to apply colors and textures to model surfaces. Different appearances can distinguish wood, glass, metal, masonry, flooring, and other materials.

The 2026 edition adds material display options, including greater control over ambient occlusion and roughness map interpretation. Users can also select preferred material thumbnails, making large material collections easier to navigate.

### Shadows and Ambient Occlusion

Shadow settings help communicate the relationship between buildings, objects, and their surroundings. Ambient occlusion adds shading in areas where surfaces meet or sit close together.

The updated ambient occlusion controls include distance and color adjustments. These settings help users refine how depth and contact between surfaces appear in a model.

### Visual Styles

Visual styles control the appearance of edges, faces, backgrounds, and other display elements. Users can choose a clean technical view or an illustrative appearance suited to design presentations.

Consistent styles help make models easier to inspect and explain during design reviews.

### Scenes for Presentations

Saved scenes allow users to create a sequence of views that explains a design. Exterior perspectives, interior views, plans, and detail views can be arranged to show different aspects of the same model.

A well-organized scene collection makes it easier to return to important views as the model changes.

## 2026 Modeling and Performance Updates

### More Efficient Model Handling

The 2026 desktop edition includes changes to memory management and commonly used modeling operations. These changes are intended to make work with larger models more responsive and reliable.

Actual performance depends on hardware, model complexity, installed extensions, and the amount of geometry being displayed.

### Scaling and Rotation

Updated scaling controls make grips easier to access when geometry overlaps other objects. Rotation behavior also includes refinements intended to make model manipulation more predictable.

These changes help users position, resize, and orient elements within dense scenes.

### Scene Undo and Redo

Scene changes can be undone and redone through the editing history. This allows users to reverse certain changes to saved views without manually restoring every setting.

The feature is useful when adjusting camera positions, scene properties, and display settings during model preparation.

### Live Components

Live Components support configurable model elements. The 2026 edition extends scaling interactions and offers additional material handling options for supported components.

These capabilities can help users position and customize reusable elements within a larger design.

## DWG and CAD Interoperability

### DWG Import

SketchUp Pro 2026 includes changes to DWG import handling. Import options include organizing imported layers as groups and flattening imported linework to simplify certain CAD-to-model workflows.

DWG hatch support allows supported hatch patterns to be imported as faces or edges according to their type.

### DWG Export

The updated export workflow can preserve section planes when exporting supported 3D DWG files. Additional changes address curves, polylines, and component instance names.

These capabilities help maintain useful geometry when exchanging files with compatible CAD applications. Results should be checked in the destination application when accuracy is important.

### IFC Export

The IFC export workflow combines supported IFC options into a unified file type with expanded export settings. This supports building information modeling exchanges where the required data and receiving application are compatible.

The resulting file should be reviewed to confirm that the required geometry and attributes have been retained.

### Importing Other Assets

Supported import options allow users to incorporate existing drawings, models, and reference assets. Imported content can serve as a foundation for a new model or as a reference during design work.

Available formats and retained data depend on the source file, edition, and installed extensions.

### Trimble Connect Integration

## LayOut and Documentation

### Drawing Sheets

LayOut connects SketchUp models with documents containing viewports, dimensions, labels, annotations, and drawing elements. Users can arrange model views on pages to explain different parts of a design.

This helps connect three-dimensional modeling with two-dimensional documentation.

### Drafting Tools

LayOut 2026 adds Trim, Extend, Fillet, and Chamfer tools for working with 2D vectors. These controls support drawing refinement and help users adjust linework within documentation sheets.

### Dimensions and Annotations

Dimensions, labels, and notes explain measurements and important design details. Clear annotation improves readability and helps reviewers understand the intent of a drawing.

Documents should be checked against the required standards and measurements before being used for construction or fabrication.

### Templates and Page Layouts

Reusable templates help maintain a consistent appearance across multiple sheets. Users can organize model views, title blocks, notes, and dimensions according to the needs of a drawing set.

Linked model views can be refreshed through the supported LayOut workflow when the underlying model changes.

## Extensions and Project Organization

### Extension Support

SketchUp supports extensions that add specialized modeling and documentation capabilities. Depending on the extension, users can add tools for geometry, data handling, visualization, and other design tasks.

Compatibility and licensing vary, so extensions should be checked before being used in important work.

Groups, components, tags, and scenes help structure a model as it becomes more complex. Consistent naming makes individual elements easier to locate and edit.

### File Management

A consistent folder structure helps keep model files, imported assets, textures, and LayOut documents organized. Backups are recommended before major edits or extension changes.

When transferring a model to another computer or team member, confirm that required external assets and linked resources are included.
